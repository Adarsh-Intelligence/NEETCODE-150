## 🧠 Recommended Learning Order

1. **Arrays & Hashing**: Fundamentals of hash sets, hash maps, frequency maps
2. **Two Pointers**: Opposite direction, slow-fast, sliding approaches
3. **Sliding Window**: Subarray problems, dynamic & fixed window sizing
4. **Stack**: LIFO patterns, monotonic stack
5. **Binary Search**: Search spaces, rotated arrays, condition evaluation
6. **Linked List**: Pointer manipulation, fast & slow runner
7. **Trees**: DFS, BFS, BST properties, recursion
8. **Tries**: Prefix trees for prefix querying and search
9. **Heap / Priority Queue**: Min/max heaps, top-k elements, event processing
10. **Backtracking**: Combinations, permutations, pruning
11. **Graphs**: Adjacency lists, BFS/DFS, topological sort, union-find
12. **Advanced Graphs**: Dijkstra, Prim/Kruskal, Bellman-Ford
13. **1-D Dynamic Programming**: Memoization, bottom-up DP, state transitions
14. **2-D Dynamic Programming**: Grid traversals, LCS, knapsack variants
15. **Greedy**: Local optimal choice, interval scheduling
16. **Intervals**: Sorting intervals, merging, overlaps
17. **Math & Geometry**: Matrix math, geometry coordinate checking
18. **Bit Manipulation**: XOR tricks, bit shifting, bit masking
